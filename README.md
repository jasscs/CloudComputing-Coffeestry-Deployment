(# Coffeestry — Azure Deployment & Demo

## Project Overview

Coffeestry is a Python + Flet coffee shop management application deployed on Microsoft Azure. The system is designed to run on an Azure Virtual Machine with local SQLite storage, supporting user roles (SuperAdmin, Admin, Customer) for order and catalog management and PDF receipt generation.
